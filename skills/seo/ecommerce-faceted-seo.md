# E-Commerce SEO & Faceted Navigation Optimization

**Category:** SEO  
**Level:** Advanced / Enterprise  
**Scope:** Online Stores, Shopify, WooCommerce & Custom E-Commerce Catalogs

---

## 1. Executive Summary & Objective
E-commerce websites face unique architectural challenges: duplicate content generated by filter combinations (color, size, price, brand), crawl budget depletion from infinite faceted URLs, and product inventory churn (out-of-stock items).

This skill outlines the technical standards to maximize organic product revenue while safeguarding site crawlability.

---

## 2. Faceted Navigation & Filter URL Strategy
Faceted navigation creates millions of low-value duplicate URLs if unmanaged (e.g., `/shop?color=red&size=m&sort=price_asc`).

### Rule Matrix:
| Filter Combination | Search Demand? | Action |
| :--- | :--- | :--- |
| Single high-demand attribute (e.g. `/ayurvedic-oil/hair-fall`) | High search volume | **Static clean URL**, indexed, unique H1, canonical to self. |
| Multiple combined filters (e.g. `?color=blue&size=l&price=500-1000`) | Near zero volume | **Canonicalize** to main category OR block via `robots.txt` / AJAX. |
| Sorting / Pagination parameters (`?sort=newest`, `?page=2`) | Zero search volume | **Canonicalize** to canonical category root or use `rel="canonical"` self-pointing with clean pagination. |

---

## 3. Pagination Best Practices (2025/2026 Standards)
- **Do NOT use `noindex` on paginated pages (page 2, page 3).** Google needs them to discover and crawl deep products.
- Each paginated page should have a self-referencing canonical URL:
  - Page 2 canonical is `https://example.com/collection?page=2`
- Titles must include page number to avoid title duplication warnings:
  - `<title>Organic Ayurvedic Supplements - Page 2 | Ivate Ayurveda</title>`
- Ensure internal pagination links use real `<a href="?page=2">` tags, not JavaScript buttons.

---

## 4. Handling Out-of-Stock Products
1. **Temporarily Out of Stock:**
   - Keep page live (HTTP 200).
   - Display clear "Temporarily Out of Stock" badge with an **"Email Me When Back in Stock"** capture form.
   - Show 4–6 related in-stock product recommendations below to retain the visitor.
   - Keep Product Schema `availability: "https://schema.org/OutOfStock"`.
2. **Permanently Discontinued Products:**
   - If an exact direct replacement exists: 301 Redirect to the replacement product page.
   - If no direct replacement exists: 301 Redirect to the parent category page.
   - Never let discontinued products sit as orphaned 404 error pages if they hold valuable external backlinks.

---

## 5. E-Commerce On-Page Product Optimization
- **Unique Product Descriptions:** Never copy manufacturer / wholesale description boilerplate. Write 250+ words of unique, benefit-led copy.
- **High-Resolution Compressed Images:** Serve `.webp` or `.avif` with descriptive naming (`ivate-pure-amla-juice-500ml.webp`).
- **Customer Reviews & UGC:** Integrate real schema-verified reviews directly on the product detail page.
